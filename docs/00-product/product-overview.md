# Sortres Product Overview

## What Sortres is

Sortres is an AI-assisted candidate screening platform for HR teams and
recruiters. It helps users turn a job description and a batch of PDF resumes
into a transparent shortlist workflow.

## Core value

Sortres reduces manual resume-review time while preserving recruiter control:

- AI structures job and resume information.
- Deterministic logic calculates candidate fit scores.
- Recruiters can review requirements, source resumes, and score breakdowns.
- Candidate stages support the screening-to-hiring workflow.

## Current product workflow

```text
Create job → extract/review requirements → activate job → upload PDFs
→ process and score candidates → review insights → update candidate stage
```

## Product boundary

Sortres is a candidate shortlisting and decision-support tool. It is not a full
ATS, scheduling platform, payroll product, or autonomous hiring system.

## Trust statement

AI assists with extraction and narrative insight. The numeric score and fit band
are calculated deterministically from structured skills and experience. Human
review remains necessary for consequential hiring decisions.
