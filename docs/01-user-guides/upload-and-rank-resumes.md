# Upload and Rank Resumes

1. Open an active job’s Candidates page.
2. Upload PDFs through the resume dropzone.
3. Observe processing status; the list refreshes every two seconds while work is
   active.
4. When scoring completes, candidates are sorted highest-score first.
5. Open a candidate to inspect the source PDF, score, skill comparison, score
   breakdown, summary, strengths, weaknesses, and interview questions.

PDFs must meet the current size/page/batch limits. A resume that fails processing
shows a failed state; eligible failures can be retried.
