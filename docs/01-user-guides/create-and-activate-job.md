# Create and Activate a Job

1. From Jobs, select **Create Job**.
2. Enter a title and paste the complete job description.
3. Select the extraction action on the job detail page.
4. Wait for requirements extraction to finish. The page polls while it is active.
5. Review the extracted requirements. Correct skills or experience requirements
   if needed.
6. Activate the job once the requirements reflect the role.
7. Use **Open Candidates** to begin uploading resumes.

If extraction fails, resolve the issue or retry extraction from the failed state.
Only active jobs are eligible for candidate scoring.
