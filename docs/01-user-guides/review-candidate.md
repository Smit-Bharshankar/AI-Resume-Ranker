# Review a Candidate

The Candidate Profile combines source evidence and generated decision support:

- Original PDF via short-lived authenticated access.
- Processing status and recruiter stage.
- Deterministic score, recommendation band, and match breakdown.
- Required-skill comparison.
- AI-generated summary, strengths, weaknesses, and interview questions.

Use the breakdown to understand why a score was produced. Check source material
when extracted skills/experience appear incomplete, and do not rely on AI text
as the sole basis for a hiring decision.
