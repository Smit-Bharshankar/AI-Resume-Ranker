# Candidate Stages

Use stages to record the recruiting decision independently of AI processing:

- **New** — not yet reviewed.
- **Shortlisted** — worth further consideration.
- **Interviewing** — actively in the interview process.
- **Rejected** — no longer progressing.
- **Hired** — selected candidate.

Sortres enforces valid stage transitions. Changing a stage does not change the
candidate score, rerun analysis, or modify the source resume.
